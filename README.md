# AI Study Planner 📚

AI Study Planner is a smart web-based application designed to help students manage study schedules, notes, productivity, and focus sessions efficiently.

---

# 🚀 Features

* 📊 Interactive Dashboard
* 📝 Smart Notes System
* ⏰ Pomodoro Study Timer
* 📈 Study Analytics
* 🎯 Goal Progress Tracking
* 🔥 Study Streak System
* 📱 Responsive User Interface

---

# 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage
* VS Code
